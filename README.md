# Estúdio @davieopai

Estúdio de conteúdo do Instagram [@davieopai](https://instagram.com/davieopai): uma equipe de agentes do Claude Code que planeja, roteiriza, anima e acompanha os stories e Reels da conta.

## Como usar

Abra uma sessão do Claude Code com este repositório e peça em português, ou use os atalhos:

| Atalho | O que faz |
|---|---|
| `/planejar-semana` | Calendário da semana, roteiros dos Reels, tema dos stories, legendas e capas |
| `/stories-do-dia` | Sequência de stories de hoje, pronta para postar |
| `/novo-reel <ideia>` | Do roteiro ao vídeo animado final, com legenda e capa |
| `/relatorio-semanal` | Análise das métricas que você colar em `metricas/` |

## A equipe

Diretor de conteúdo, estrategista, pauteiro, roteirista de Reels, produtor de stories, animador, editor de Reels, redator de legendas, designer de capas, analista de resultados e gestor de comunidade. As fichas ficam em `.claude/agents/` e o mapa completo em `CLAUDE.md`.

## Primeiro passo

Responda às perguntas "a confirmar" em `marca/perfil.md` e mande 2 ou 3 exemplos das animações que viralizaram para o animador registrar o estilo em `marca/estilo-animacao.md`.

## O que não é automático

Não há conexão com o Instagram: os agentes não publicam nem leem métricas sozinhos. Tudo sai pronto para você postar ou agendar no app, e as métricas você cola em `metricas/`.
