# Calendário

Um arquivo por semana ISO: `calendario/AAAA-Wnn.md` (ex.: `2026-W46.md`). Criado pelo `/planejar-semana`.

Formato:

```
# Semana nn (dd/mm a dd/mm)

Foco da semana: …

| Dia | Horário | Formato | Tema | Roteiro | Status |
|---|---|---|---|---|---|
| seg 10/11 | 19h | Reels | … | roteiros/reels/2026-11-10-slug.md | roteiro / animando / pronto / postado |

Stories: tema do dia para cada dia.
```
